## 🚀 How to Run

Clone the repository:

```bash
git clone <your-repository-url>
```

Navigate to the required folder:

```bash
cd Java_Coding
```

Compile a Java program:

```bash
javac HelloWorld.java
```

Run the program:

```bash
java HelloWorld
```
